SMALL API, USEFUL REPAIRS

From almost JSON
to a Python value.

Pass in a complete document or a prefix of one. Get a string back. Use Python’s standard JSON parser for the next step.

Explore the API →
repair.py
import json
from untruncate_json import complete

partial = '{"items": [1, 2,'
repaired = complete(partial)

# {"items": [1, 2]}
data = json.loads(repaired)

KNOW WHAT YOU’RE GETTING

Repair the structure.
Review the meaning.

Untruncate repairs a document that ends too soon. It cannot recover missing values or fix every kind of malformed JSON. Unfinished keys, trailing commas, and incomplete string escapes may be discarded.

Valid, complete JSON stays unchanged. Empty input stays empty. Always validate repaired data before relying on it.
